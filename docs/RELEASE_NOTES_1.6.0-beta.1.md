# PrintFarm Assistant 1.6.0-beta.1

本次公开测试版把多色排盘加入官方工作区，并将多色规划与检修迁移到独立
受保护组件。

## 新功能与改进

- 公开版新增“多色排盘”工作区，可处理带颜色和材料信息的 3MF 工程。
- 支持零串色、满盘参考和按盘时长三种策略。
- 支持单盘最多 1、2、4 色，以及按颜色分批、混合耗材分盘和擦料塔预留。
- 支持只生成可在 Bambu Studio 继续修改的通用 `.3mf`，也支持生成经过
  切片检修的 `.gcode.3mf`。
- 多色排盘规划与检修改为调用独立 `protected_core.exe`，主程序不再导入
  多色算法模块。
- 启动多色任务前校验 `protected_core.sha256`；组件缺失、被替换或协议版本
  不兼容时会拒绝运行并提示重新安装。
- 公开版保留切片工作台、批量切片和多色排盘；手办模式与悬浮助手继续保持
  非公开。

## 本版验证

- 前端构建、研发 UI 冒烟和公开三工作区模式测试通过。
- 后端参数解析、任务构造、多色 JSON 请求和检修回调测试通过。
- 受保护组件的存在性、SHA-256 篡改拒绝和协议版本测试通过。
- 正式安装包已做临时目录静默安装，确认受保护组件与校验清单落盘、哈希一致，
  并通过静默卸载。
- 公开装配泄漏扫描会阻止私有算法源码、`protected_core.py` 和可还原核心
  实现进入公开源码树。

本轮没有由 Codex 启动 Bambu Studio 执行真实切片。多色摆盘的实际效果、
机型组合和 Bambu 检修仍需维护者在目标电脑上人工验收。

## 已知限制

- 安装包未代码签名，Windows SmartScreen 可能提示未知发布者。
- 多色排盘只接受 3MF 工程；STL/STEP 请先使用切片工作台或批量切片。
- 多色真实切片耗时明显高于单色，且“按时长”结果受剩余零件、颜色数量和
  擦料塔影响。
- 不建议把自动检修结果当作实体打印安全的唯一依据；正式打印前仍应逐盘
  检查支撑、干涉和擦料塔。
- 支持 Windows 10 1809 x64 和 Windows 11 x64，不支持 32 位系统。

## 安装包校验

请以 Releases 页面附带的 `SHA256SUMS.txt` 和
`COMPONENT-SHA256SUMS.txt` 为准。不要使用来源不明或校验值不一致的安装包。
