公开测试版新增多色排盘，并把核心规划与检修放入独立受保护组件。

## 主要功能

- 切片工作台、多色排盘和批量切片。
- STL、3MF、STEP/STP 输入；多色排盘支持带颜色信息的 3MF。
- 多色零串色、满盘参考和按盘时长策略。
- 通用可编辑 `.3mf` 与可直接打印 `.gcode.3mf` 输出。
- 普通自动摆盘、自动朝向、参数修改、克隆、最省空间和最少支撑。
- 受保护组件 SHA-256 完整性检查与协议版本检查。
- 每用户安装，不需要管理员权限。
- 配置、日志和模型数据全部留在本机。
- 安装包已完成临时目录静默安装/卸载和组件哈希落盘检查。

## 本版说明

- 多色入口在公开版开放，手办模式和悬浮助手继续不公开。
- 多色排盘只接受 3MF 工程，并在提交时创建独立输出目录。
- 本轮只完成离线构建、协议和 UI 测试，没有由 Codex 自动启动 Bambu Studio。
  维护者仍需在主机上人工验证真实多色摆盘、切片和打印前检查。
- 安装包未代码签名，SmartScreen 可能提示未知发布者。

请只从本仓库 Releases 下载，并在运行前核对 SHA-256。
