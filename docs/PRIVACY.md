# 隐私说明

打印农场助手以本地处理为默认原则。

## 不上传的内容

程序不会自动上传：

- 导入的模型或切片结果；
- 文件名、文件夹结构或输出路径；
- Bambu Studio 账号、访问码或打印机凭据；
- 使用统计、操作日志、OCR 图片或识别结果；
- 打印机状态或打印历史。

## 本地保存的数据

默认用户数据目录：

```text
%LOCALAPPDATA%\PrintFarmAssistant
```

可能包含：

- `config.json`：打印机、工艺、耗材、输出目录等偏好；
- `usage.json`：本机操作次数和最近事件；
- `user_rules_*.json`：用户习惯和一句话参数规则；
- 日志文件：运行状态、切片输出和错误诊断。

这些数据只用于本机功能和故障排查。用户可在设置中清除打印习惯，也可在
退出程序后手动删除用户数据目录。

## 网络访问

本地界面通过 `127.0.0.1` 与后台服务通信。程序不会发送遥测，不会自动更新，
也不会默认开机启动。

## 第三方软件

Bambu Studio 的数据处理遵循 Bambu Lab 自己的隐私政策。打印农场助手不会
读取或保存 Bambu Studio 的账号密码、OTP 或访问码。
