# PrintFarm Assistant 1.5.0-beta.1

这是“打印农场助手 / PrintFarm Assistant”的首个公开测试版。

## 新功能与改进

- 产品正式改名为 PrintFarm Assistant / 打印农场助手。
- 提供切片工作台和批量切片两个公开工作区。
- 支持 STL、3MF、STEP、STP 输入并生成可直接打印的 `.gcode.3mf`。
- 支持普通自动摆盘、自动朝向、参数修改、克隆、最省空间和最少支撑。
- 安装改为免费的 Inno Setup，每用户安装，不需要管理员权限。
- 安装和升级时不会关闭 Bambu Studio。
- 支持助手运行中覆盖安装，以及助手与 Bambu Studio 同时运行。
- 用户配置、日志、OCR 和使用记录迁移到 `%LOCALAPPDATA%\PrintFarmAssistant`。
- 增加单实例互斥，重复启动会激活已有窗口。
- STEP 转换拆成独立 GPL `step_converter.exe`，主程序不再链接 Gmsh。
- 公开版后端拒绝多色、手办和悬浮助手调用，并阻止网址参数绕过。
- 修复 ASCII STL 在预分析阶段被误判为二进制 STL 后卡住的问题。
- 未处理异常会结束等待中的任务并写入日志，不再一直显示“切片中”。
- 安装尾声的旧版清理和环境提示改为容错执行，清理失败不会中断安装。
- 修复最省空间合盘被 Bambu 误判为空盘后回退成“每个零件一个文件”的问题，
  合盘现在会先按助手坐标切片，必要时自动增大间距重试并输出单个多盘文件。
- 不自动开机启动，不发送遥测，不自动更新。

## 已验证

- 后端参数解析和真实 Bambu 命令构造。
- UI 公开模式、导入、任务轮询、OCR 和日志。
- 打包版真实 STL 切片。
- 打包版真实 STEP 切片。
- 全新安装。
- 助手运行中覆盖安装。
- 助手与 Bambu Studio 同时运行。
- 卸载时不关闭 Bambu Studio。

## 已知限制

- v1.5.0-beta.1 暂未进行代码签名，Windows SmartScreen 可能提示未知发布者。
- 本轮不包含多色排盘、手办模式和悬浮助手。
- 最省空间、最少支撑和 Bambu 桌面自动化组件保持闭源。
- 支持 Windows 10 1809 x64 和 Windows 11 x64；不支持 32 位系统。
- 需要用户自行安装 Bambu Studio 和 WebView2。
- 模型的第三方拖入兼容性仍有边界问题，后续版本继续处理。
