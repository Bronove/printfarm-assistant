拓竹助手 - 使用说明
========================

一、怎么用
  1. 双击桌面图标【拓竹助手 1.5】打开软件。
  2. 把模型文件（.stl / .3mf / .stp / .step）或整个文件夹直接拖进中间的拖拽区域，
     松手后只是添加文件（拖拽区会显示已添加的文件名），不会立刻切片；
     先核对下方“当前参数”显示的识别结果，确认无误后点【开始切片】。
     队列右上角主按钮左侧有下三角：可切换【开始切片】和【开始摆盘】。
     “开始切片”输出可打印的 .gcode.3mf；“开始摆盘”只生成可继续编辑的
     通用 .3mf，不包含 G-code。
     也可以点击拖拽区域自己选择文件，流程相同。
     拖入后拖拽区会列出每个文件（可继续追加），方便核对到底导入了什么。
     （.stp/.step 是 CAD 格式，软件会自动转成 STL 再切片，会稍慢一点。）
     （导入时自动检测破面/非流形面：能修的直接修复，修不了的保持原样，
       不会因为网格有破洞而切不了。）
  3. 拖拽区底部有“打印机”下拉框：列出 Bambu Studio 里所有机器预设，
     选哪个就切哪个（自动配好对应工艺和 PLA 耗材），下次打开仍保留你的选择。
  3. 最上面一行的“参数需求”是选填的：
     - 留空 = 用默认参数；
     - 想改参数就写文字，例如：填充 50%、层高 0.28、树状支撑、
       无支撑、网格、蜂窝、3D蜂窝、冷却板、不要自动定向……
     - **直接说/转写整句话也行**：软件会自动滤掉语气词和废话
       （嗯、那个、帮我、然后、就行……），纠正同音错字
       （树支→树状、网个→网格、风窝→蜂窝、拼版→摆盘……），
       并把中文数字转成数值（打八个→8个、百分之五十→50%、
       零点二→0.2），一句话就能把需求讲完。
     - **换耗材/材料**：写“材料PETG”“用ABS”“换TPU”“尼龙”
       “碳纤维”等，软件自动匹配当前打印机支持的 Bambu 耗材预设；
       当前机型没有该耗材时不会乱换，保持原耗材。
       目前支持四类基础耗材：PLA / PETG / ABS / TPU，以及它们的
       特殊变体：丝绸、碳纤维、大理石、夜光、荧光、木质、金属、
       哑光、透明、星空、闪粉等。切片产物的耗材会直接写入文件，
       用 Bambu Studio 打开就能看到。
       PETG 的常见语音误转（pet、ptg、pegt 等）会自动纠正；碰到
       没见过的写法会用相似度兜底，识别结果带"？"提示核对。
     - **特殊耗材提醒**：识别到特殊耗材时会自动给出打印建议，
       例如碳纤维/夜光/木质等含粉耐磨料会提醒用 ≥0.4mm 硬化喷嘴
       （不建议 0.2mm），丝绸/TPU/PETG 会提醒干燥箱或打印前烘干，
       ABS 会提醒密闭箱体与通风。提醒会显示在状态栏、弹窗和日志里。
     - **去掉支撑**：写“不要支撑”“无支撑”“去掉支撑”“支撑去了”
       “关支撑”“不要开支撑”“支撑不开”都行，都会按无支撑切片；
       默认是自动树状支撑，只有明确说了不要才关闭。
     - **一个零件打多份**：写“打 5 个”或“克隆 3 个”，软件会把
       这个零件复制成对应份数，自动用支撑感知摆盘拼到一块盘上
       （拼不下会自动拉开间距重摆，保证支撑不碰邻居），一盘一次切片。
       整盘切单个 3MF 时默认保持原布局，不自动翻转。
       开启隐藏 Z 缝后，多零件 3MF 按手办模式处理：体积最大件为主体，
       第二件达到最大件体积 60% 时也算主体（最多两个）；主体保留原朝向，
       其余部件直接使用 Bambu Studio 自带的自动朝向，不再执行自定义最大平面检测。
       3MF 按顶层 build item 拆分，组合件不会被拆散，原对象名称会保留。
       原文件已经有多个打印盘时默认整套保留，不会拆散后强行合成一盘。
       STL/STEP 等没有原始布局的模型，日常切片同样优先把真实大平面朝下；
       日常朝向交由 Bambu Studio 自带自动朝向判断。
       只有明确写“最省空间”才改用紧凑定向（把模型竖起来
       极限塞盘）。自动选底面后放不下时，会提示减少数量或开启最省空间。
     - **一句话给多个文件分配不同参数**：拖入多个文件后，可以用序号
       或文件名引用，例如“模型1用PETG填充50，模型2无支撑层高0.16，
       第三个默认”，或“i6完成版001碳纤维，第二个ABS”。引用之前的内容
       是所有文件的公共参数；每个文件会在拖拽区列表里显示自己那份参数，
       核对后再点【开始切片】。
     - **直接把别人给的建议粘进来**（新手友好）：不用自己找菜单，
       支持“内墙速度150、外墙80、墙4层、熨烫开、裙边8、顶层6、
       底层4、接缝最近、逐对象打印、不要裙边”这类说法，也支持
       原始写法 wall_loops=4;brim_width=8。识别出的结果会显示在
       “当前参数”里，核对后再开始切片。
     开始前状态栏会显示“已应用”的参数，方便核对。
  4. 批量模式：拖入一个或多个模型后，点右下角【批量文件夹…】或开始切片。
     软件会先按 Bambu 的零件结构拆开每个文件，再按所选机型打印板尺寸摆盘。
     - 基础批量：按源文件分别处理，放不下就分多盘，所有盘合成一个 3MF；
     - 自动摆盘：把所有选中文件的零件尽量装满每盘，不够就加盘；
     - 最省空间：优先减少盘数，使用更紧的占地方向和间距；
     - 最少支撑：比较候选方向，按真实切片后的支撑耗材量选方向。
     “最省空间”和“最少支撑”不能同时开启；“自动摆盘”可以和“最少支撑”
     同时开启。批量结束后在输出目录生成“切片报告.txt”和参数对照文件。
  5. 输出文件夹默认是 桌面\切片文件，在“输出到”一行改成你要的位置。
  6. 切片过程中按钮会变成【停止】，随时点一下就能中断
     （正在切的那个模型会取消，已完成的不受影响）。
  7. 窗口可以随意拉大、最大化，界面上的卡片、文字、按钮会跟着
     一起缩放重排，不会重叠错位。

二、切片参数
  默认配方以当前机型配置为准：0.2mm 层高、15% 网格填充、
  树状支撑（仅打印板）、日常优先大平面（找不到时回退拓竹自动定向）。
  机型、工艺和耗材会保存在程序目录的 config.json，界面上的选择优先。

三、几点说明
  - 模型超出打印板时，软件不会自动缩放模型尺寸；会清理明显坏面，
    然后停止并提示换更大机型或手动调整模型。
  - 单个已经摆好的多零件 .3mf（例如“一对单盘”）默认原样整盘切，
    保留原有的缩放、镜像和位置；只有明确开启自动摆盘/最省空间/
    最少支撑时，才会拆件重排。
  - 批量切片时，一个失败不影响其他模型，点右上角【日志】查看详情。
  - 每个模型生成一个 “模型名.gcode.3mf”，重名会自动加序号，不会覆盖。

四、常见问题
  - 提示“没有找到文件夹”：确认名称没打错，且文件夹在桌面/文档/下载里，
    或直接输入完整路径。
  - 切片失败提示“此文件不包含任何几何数据”：个别 3mf 模型格式问题，
    换回 STL 格式再试。
  - 日志里出现 exit -17：预设文件加载失败，检查 config.json 里的
    打印机/工艺/耗材名称是否和 Bambu Studio 里的一致。

五、程序文件位置
  主程序：安装目录\拓竹助手.exe（开发时才是 切片软件.pyw）
  配置：  config.json（自动保存输出文件夹等）
  引擎：  bambu_cli\（调用本机 Bambu Studio 的官方命令行切片）

六、使用数据（帮助改进软件）
  - 软件只在本机记录使用情况（usage.json），不会联网上传。
  - 数据仅含：软件版本、系统、打印机、识别出的打印参数、
    切片成败与耗时，以及参数需求原文（文件名已自动打码）。
    不包含模型文件内容与路径。
  - 状态栏【导出数据】里的"导出数据包"会把 usage.json 和
    切片日志打包成 zip，把这个 zip 发回给开发者即可。

七、自我学习（适配你的习惯）
  - 每次切片成功且你不再修改参数，软件会把这次输入记成"认可样本"。
  - 同一句话出现 2 次以上且识别结果一致，会形成个人短语规则；
    你稳定常用的参数（层高/填充/图案/支撑）会成为你的"习惯默认"。
  - 之后没写到的参数会自动按你的习惯补上，识别结果显示"含个人习惯"；
    你显式输入的参数永远优先。
  - 学习数据只在本机（user_rules_*.json），可在【导出数据】里
    查看统计或一键清除。
  - **账号与习惯管理**：状态栏【习惯】打开"用户习惯记录"面板，
    像输入法个人词库一样管理：可以新建/切换/删除账号，每个账号
    一套独立的学习数据；能查看习惯默认、逐条开关/删除短语规则、
    看到高频说法（词频），或一键清除当前账号的学习数据。
